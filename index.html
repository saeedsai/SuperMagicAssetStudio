Main workflow

  1. Choose a character mode in Project.
  2. Choose Bundled or External JSON image storage.
  3. Import PNG or JSON files.
  4. Arrange layers, crop, color, and animate.
  5. Save JSON or export PNG/GIF.

Sections in the sidebars are collapsible to keep the UI simpler.

For AI/automation, use the built-in AI panel, window.SuperMagicAssetStudioAPI, or the PowerShell CLI.

Sprite sheet extraction

Use Import → Manual crop & split to draw rectangles or freeform boundaries, Import → Auto-split multiple sprites to detect transparent isolated figures and then refine them with extra manual freeform cuts, and Import → Remove image background for edge-connected solid-color backgrounds. Extracted PNGs enter the assignment queue (view, animation, frame and part). See IMAGE_TOOLS_API.md and ASSET_CREATION_GUIDE.md.

PowerShell / Agent CLI

Use SuperMagicAssetStudio.ps1 to create, modify, review, render, and export assets from a terminal. Requires Node.js 20+. Example: pwsh -File ./SuperMagicAssetStudio.ps1 -Project ./player.json -CommandFile ./cli-example-commands.json. See CLI_API.md for the complete command reference.
